# Airline Delay Dashboard – Power BI Report

A professional multi-page Power BI dashboard designed to analyze airline delays, operational disruptions, and airport performance across the United States.

## Project Overview

This report was built to provide an executive-level overview of airline punctuality while allowing deeper root-cause analysis through interactive visuals and navigation. It combines KPI monitoring, trend analysis, and decomposition techniques to uncover where delays happen, why they happen, and which airports or carriers are most affected.

The dashboard is structured as a business-ready reporting solution with a landing page, synced filters, and page navigation.

## Report Pages

### 1. Home Page

* Interactive landing page with airport selector
* Navigation between dashboard sections
* Synced slicers across all report pages

### 2. Delays Overview

* Total Flights
* Delay %
* Average Delay (minutes)
* Delayed Flights
* Delay trend over time
* Airport rankings by delay rate
* Weather vs delay relationship analysis

### 3. Delay Causes Analysis

* Total Delay Minutes
* Weather Delay %
* Carrier Delay %
* Late Aircraft Delay %
* Delay cause distribution
* Top affected airports
* Decomposition Tree for root cause exploration

## Dashboard Features

* Multi-page report design
* Interactive slicers and synced filters
* Dynamic page navigation
* Drill-down decomposition tree
* KPI cards and executive summaries
* Custom UI / landing page experience
* Clean dashboard styling and layout

## Key Business Insights

* Late aircraft arrivals represent one of the largest delay drivers.
* Certain major hub airports show consistently higher delay rates.
* Weather contributes significantly during selected periods and locations.
* Carrier-related delays vary strongly by operator.
* Trends over time help identify operational improvement opportunities.
